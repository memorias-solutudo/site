# Pacote de continuidade d'A Fonte — parte pública

Montado em 01/10/2026 para levar o projeto a outra conta do Claude. **Comece por `00-LEIA-PRIMEIRO.md`.**

Esta pasta guarda só a parte do pacote que pode ficar num repositório público:

- os guias, de `00` a `07`, mais `CLAUDE.md` e `INSTRUCOES-DO-PROJETO.txt`;
- a ficha de cada empresa;
- os scripts que montam as centrais;
- a resposta sobre métricas de produto.

O **zip completo**, `A-Fonte_pacote-de-continuidade.zip`, com 100 arquivos, foi entregue na conversa de
01/10/2026. Ele traz também material que **não vem para cá** de propósito:

| Material | Por que fica só no zip |
|---|---|
| O dossiê dos agentes da Execon | traz o CNPJ e os fatos barrados |
| As centrais convertidas em texto | já estão publicadas no `soluintel`, e as cópias tiveram os dados de patrocinador retirados |
| Os pedidos reais feitos aos agentes | citam o CNPJ |
| As cópias dos documentos de regra e dos agentes | o original está no `soluintel` |

Os documentos de regra e os agentes estão no repositório `memorias-solutudo/soluintel`, em `docs/` e
`.claude/`.
